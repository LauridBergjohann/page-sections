# Minimal Page Sections demo

One page, one shell, two sections. Start with [src/routes/+page.svelte](src/routes/+page.svelte) and [src/routes/+layout.svelte](src/routes/+layout.svelte).

From the repository root:

```sh
npm ci
npm run dev:demo
```

Open http://127.0.0.1:5173. For a production build and preview, run `npm run demo` (port 4173).

There is no documentation navigation, highlighting engine or icon dependency in this app. The [website](../website) contains the guides and interactive examples; [tests](../tests) contains the regression fixtures.
