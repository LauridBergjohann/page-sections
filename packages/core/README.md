# @page-sections/core

The framework-independent foundation of Page Sections: typed content models, shared layout rules and navigation helpers for content-driven websites. Use it on its own or through the Svelte component package.

- **Serializable content:** model pages, sections, cards and code examples for JSON files or your own CMS.
- **Consistent layouts:** share responsive calculations, breakpoints and design tokens across renderers.
- **One navigation tree:** derive active menu entries, sidebar branches and breadcrumbs from the same structure.
- **Extensible sections:** register custom section types alongside the built-in content models.
- **Independent of the UI:** no runtime dependencies or DOM requirement; usable in browser and server code.

## Installation

```sh
npm install @page-sections/core
```

Requires Node `>=22.12.0`. For ready-made Svelte components, install [@page-sections/svelte](https://www.npmjs.com/package/@page-sections/svelte), which includes core and re-exports its types.
